Linux To Go

什么是Linux To Go

Linux To Go 通常指的是可以在移动存储设备（如 U 盘、移动硬盘）上运行的 Linux 操作系统，也被称为 “便携 Linux” 或 “Live Linux”。它最大的特点是无需安装到计算机的本地硬盘，插入设备后即可从启动菜单选择运行，使用完毕后拔出设备也不会对主机的原有系统产生影响。

制作Linux To Go

我使用的设备如下

  • 华硕无畏14oro笔记本
  • Kingston DataTraveler 32GB
  • VMware® Workstation 17 Pro(17.6.3 build-24583834)
  • 安装的是Fedora WorkStation 42

制作流程

下载 Fedora 系统镜像

我的笔记本是AMD处理器，故选择AMD处理器的镜像文件，大家根据自己的实际情况选择下载。

使用 VMware虚拟机进行安装

找到VMware右键以管理员身份运行

  1. 新建虚拟机
  2. 选择自定义
  3. 选择下一步
  4. 选择稍后安装操作系统
  5. 选择 Linux，下一步
  6. 选择你要安装的位置
  7. 选择处理器和内核的个数
  8. 处理器个数可以使用 systeminfo查看
  9. 搜索计算机管理 -> 设备管理器 -> 处理器 查看内核个数
  10. 设置虚拟机内存
  11. 默认选择下一步
  12. 默认选择下一步
  13. 选择 SCSI(S)
  14. 选择使用物理磁盘
  15. 选择你要使用的物理磁盘， 我的设备只有一个C盘，因此是 PhysicalDrive1 在你的设备上就不一定了，可通过 计算机管理 -> 存储 -> 磁盘管理 来确定

  16. 选择下一步
  17. 加载下载好的ISO镜像文件
  18. 完成安装
  19. 最后更改一下固件类型，编辑虚拟机 -> 选项 -> 高级 选择UEFI
  20. 进入系统进行虚拟机常规安装

运行Linux To Go

完成上述过程后关闭虚拟机，退出U盘，关闭电脑，重启进入系统引导界面（不同设备方法不同我的设备是华硕笔记本，开机后按F2键进入BIOS管理界面再按F8进入系统引导界面）选择fedora等待开机后就可以正常使用了。
